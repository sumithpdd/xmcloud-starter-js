# Search Component - Demo Search Terms

This document provides recommended search terms to demonstrate the search component functionality, including featured FAQ answers.

## Featured FAQ Search Terms

These search terms will trigger featured FAQ answers (highlighted in purple):

### 1. **"What is CIPFA"**
- **Expected Result**: Featured answer explaining what CIPFA is
- **Category**: FAQ
- **Read Time**: 3 minute read
- **Author**: By CIPFA Staff

### 2. **"How do I join CIPFA"** or **"join CIPFA"**
- **Expected Result**: Featured answer about membership application process
- **Category**: FAQ
- **Read Time**: 5 minute read
- **Author**: By CIPFA Staff

### 3. **"CPD requirements"** or **"What are the CPD requirements"**
- **Expected Result**: Featured answer about Continuing Professional Development requirements
- **Category**: FAQ
- **Read Time**: 4 minute read
- **Author**: By CIPFA Staff

### 4. **"MyCIPFA"** or **"How do I access MyCIPFA"**
- **Expected Result**: Featured answer about accessing the MyCIPFA portal
- **Category**: FAQ
- **Read Time**: 2 minute read
- **Author**: By CIPFA Staff

## Search Features to Demonstrate

1. **Autocomplete Suggestions**: Type partial search terms to see suggestions
2. **Featured Answers**: Search for FAQ terms to see highlighted answers
3. **Category Tags**: Show different categories (FAQ, Training, Service, etc.)
4. **Read Time**: Show estimated reading time for articles
5. **Author Information**: Show author attribution
6. **Sorting**: Demonstrate sorting by relevance vs. date
7. **Category Paths**: Show breadcrumb navigation paths
8. **Tags**: Show topic tags on results

## Tips for Demo

- Start with a simple search like "CIPFA" to show general results
- Then search for specific FAQ terms to show featured answers
- Use sorting to show different result orders
- Show autocomplete by typing slowly
- Demonstrate clicking on suggestions to auto-fill search
